# Agribusiness Bankability Index (ABI) — Demo Version 0.1

A research demonstration prototype for *"Developing and Validating the Agribusiness
Bankability Framework for Food Systems Transformation through Novel Financing Models in
Zimbabwe."* Sponsored for live demonstration by GigaFood Africa.

## Start here

1. Read `AGENTS.md` — ground rules and reading order.
2. Read every file in `docs/` in the order listed in `docs/INDEX.md`.
3. Execute `docs/25_AGENT_EXECUTION_PLAN.md` phase by phase.
4. Verify `docs/26_DEFINITION_OF_DONE.md` before declaring the build finished.

## Status

Research prototype. Not a production lending or credit-decision system. All scores,
bands, gates and recommendations are provisional pending empirical validation.
